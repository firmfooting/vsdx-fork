# Roadmap: vsdxkit modernisation

Distribution `vsdxkit` (import `vsdx`), fork of dave-howard/vsdx.
Base: upstream v0.6.1 + Visio-faithful feature set (see git log).

## Done

- [x] Annotation modernisation to PEP 604 unions (Pyrefly 0 errors)
- [x] `pyproject.toml` packaging; setup.py/requirements.txt removed;
      version single-sourced from `vsdx.__init__.__version__`
- [x] Distribution renamed `vsdxkit`; import stays `vsdx`; wheel+sdist
      build verified by install-import test
- [x] ruff adopted (default rules + import sorting + formatting);
      remaining findings are the documented ratchet
- [x] pyrefly adopted (preset `basic`, ratchet start)
- [x] `vsdxfile.py` slimmed 1,292 → ~982 lines: masters-import →
      `masters.py`, jinja templating → `templating.py`, zip-XML
      persistence → `xmlio.py`; `VisioFile` keeps the full public API
      via mixins; `python_requires >= 3.10` (EOL 3.7–3.9 dropped)
- [x] v0.6.3 release (tag + wheel)
